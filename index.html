ChatGPT on Windows, connected to a server over SSH

Install the ChatGPT desktop app, switch on an SSH host, and let Codex fix the connection when it fails. About a minute of video, then the same steps in writing.

67 seconds · Windows 10 and 11 · screens are simplified illustrations; labels may differ in your app version.

Before you start

  • A Windows 10 or 11 PC and a ChatGPT account.
  • A Linux server you can already log in to with a password from a terminal.
  • The server listed as a host in your SSH config file, C:\Users\<you>\.ssh\config, for example:
Host devbox
    HostName server.example.com
    User yourname

The app shows Norwegian labels if Windows is set to Norwegian. They are given in grey below.

Steps

  1. Install the app from the Microsoft Store

    Open the Microsoft Store, search for ChatGPT, and pick the app whose publisher is OpenAI. Skip the look-alikes. Click Get.

  2. Open the app and log in

    Click Open, then Log in. Sign-in finishes in your browser.

  3. Switch on your server

    Open Settings › Connections (Tilkoblinger) › SSH. Under SSH connections from this PC (SSH-tilkoblinger fra denne PC-en), switch on your host. If it isn't listed, click Add (Legg til).

    The first attempt often fails with Error · SSH connection failed (Feil · SSH-tilkobling mislyktes). Hover the ⓘ icon to see why; Host key verification failed is typical when the PC has never logged in to that server with a key.

  4. Ask Codex to fix passwordless login

    Start a new chat on this PC and ask:

    Fix passwordless SSH login to devbox

    Codex checks your SSH setup, creates a key if the PC has none, and gives you a short command to add the key on the server. Run that command in a terminal where you are logged in to the server, then type done in the chat. Codex tests the login.

    Never type the server password in the chat. Type it only in your own terminal window.

  5. Ask Codex to install Codex CLI on the server

    If the host then shows Codex CLI is not installed on this remote machine (Codex CLI er ikke installert på denne eksterne maskinen), ask in the same chat:

    Codex CLI isn't installed on devbox. Install it over SSH now.

  6. Reconnect and pick a folder

    Back in Settings › Connections › SSH, click Reconnect (Koble til på nytt). If Codex asks you to sign in on the server, complete it. When the host says Connected (Tilkoblet), click the folder icon on the host row and open a project folder on the server. Chats in that project now run on the server.

Doing steps 4 and 5 by hand

If you'd rather not let Codex do it, the same fixes take three commands in PowerShell on the PC. Replace devbox with your host alias.

# 1. Accept the server's host key (answer "yes" once, then log out)
ssh devbox

# 2. Create a key and copy it to the server (asks for the server password once)
ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh devbox "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

# 3. Check that login no longer asks for a password, and that Codex is found
ssh devbox "bash -lc 'which codex'"

If which codex prints nothing, install Codex CLI on the server (it needs Node.js) and sign in once:

npm install -g @openai/codex
codex

The app starts Codex through the server's login shell, so codex must be on the PATH there.

Troubleshooting

Status in the appWhat it meansFix
Error · SSH connection failed, Host key verification failedThe PC doesn't trust the server yet, or has no key it accepts.Step 4, or ssh devbox once and answer yes.
Connecting · Codex CLI is not installed on this remote machineSSH works, but codex isn't on the server's login PATH.Step 5, or install it by hand.
Connected, but chats failCodex on the server isn't signed in.Click Reconnect and complete the sign-in, or run codex on the server once.
The host isn't listedIt isn't in your SSH config file.Add a Host entry, or use Add.

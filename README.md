# gpt-install

Install the ChatGPT desktop app on Windows and connect it to a server over SSH: a one-minute video and written steps.

Live at <https://timknutsen.no/gpt-install/>. Served by GitHub Pages from `main`; the custom domain comes from the `timknutsen.github.io` user site.

The video was made with Remotion and an ElevenLabs voice. Host names in it are placeholders.
